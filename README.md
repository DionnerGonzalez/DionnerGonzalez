About me

I'm Dionner Gonzalez, a developer interested in understanding technology from the inside out.

I enjoy programming, experimenting with software, exploring operating systems and learning how things work beneath the surface.

My main interests revolve around systems programming, open-source software, Linux and the freedom to build, customize and understand technology.

I believe in learning by building, questioning how things work and continuously improving through experimentation.

«Understand the system. Build the solution. Share the knowledge.»
